# 🎧 Audio ML: Urban Soundscape Classification

This project focuses on building an intelligent machine learning system to automatically classify and recognize urban environmental sounds such as sirens, car horns, dog barks, drilling, and street music.

## 🚀 Overview
Urban environments generate a wide variety of sounds that are important for applications like smart city monitoring, noise pollution analysis, and public safety systems. This project uses Machine Learning and Deep Learning techniques to classify these sounds efficiently and accurately.

## 🧠 Key Features
- Automated classification of urban sounds into multiple categories
- Feature extraction using MFCC, Mel-Spectrogram, Chroma, and Zero-Crossing Rate
- Implementation of both ANN and CNN models
- Comparative analysis of model performance
- Real-time applicability for smart city systems

## 🛠️ Tech Stack
- Python
- Librosa
- TensorFlow / Keras
- PyTorch
- Scikit-learn
- NumPy, Pandas, Matplotlib

## 📊 Dataset
- UrbanSound8K dataset (8,732 labeled audio clips across 10 classes)
- Download Dataset:- https://www.kaggle.com/datasets/chrisfilo/urbansound8k

## ⚙️ Methodology
1. Data Collection
2. Audio Preprocessing (resampling, noise reduction, augmentation)
3. Feature Extraction (MFCC, Spectrograms)
4. Model Training (ANN & CNN)
5. Evaluation (Accuracy, Confusion Matrix)

## 📈 Results
- ANN Accuracy: **95.68%**
- CNN Accuracy: **84.5%**
- ANN performs better on simpler sound patterns
- CNN captures complex time-frequency patterns effectively

## 🌍 Applications
- Smart city monitoring
- Noise pollution control
- Emergency sound detection (sirens, alarms)
- Urban analytics and planning

## 🔮 Future Work
